模块以 React 函数组件为最小单元组织每个邮件类型：`Layout.tsx` 作为所有邮件共享的根布局（包裹 `Html/Head/Preview/Tailwind/Body/Container` 并注入尾部签名），各业务模板 `ConfirmSubscription.tsx`、`NewGuestbook.tsx`、`NewReplyComment.tsx`、`NewslettersTemplate.tsx` 均通过 `<Layout previewText=...>` 组合复用；`_components.ts` 集中 re-export `@react-email/*` 下的基础 UI 原语，避免在业务模板中直接依赖第三方包；`index.tsx` 是 react-email 默认的示例入口，用于本地预览渲染。Newsletter 正文采用 Markdown 驱动：`newsletters/*.md` 存放纯文本源，由 `NewslettersTemplate.tsx` 通过 `react-markdown` 渲染，并通过自定义 `img` 组件适配邮件客户端图片宽度。静态资源（logo、横幅）通过 `../config/email` 中的 `emailConfig.baseUrl` 拼接绝对 URL，保证邮件客户端可正确加载。
