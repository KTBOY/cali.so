- 每个邮件模板导出一个默认 React 函数组件，props 统一使用具名可选参数并提供空值默认值，便于调用方按需传入。
- 所有模板必须被 `<Layout previewText={...}>` 包裹，由 Layout 统一处理 `<Head>/<Preview>/<Tailwind>` 以及底部签名区。
- UI 原语一律从 `./_components` 导入而非直接引用 `@react-email/*`，以便集中管理依赖版本与别名。
- 外部图片与横幅通过 `../config/email` 的 `emailConfig.baseUrl` 拼接成绝对 URL，避免相对路径在邮件客户端失效。
- 用户生成内容（留言、评论、Newsletter 正文）统一通过 `react-markdown` 渲染，并在需要时自定义 `img` 组件以控制最大宽度。
