- 所有需要浏览器 API 的组件在文件首行标注 `'use client'`，并通过 `React.useState` / `React.useEffect` 管理挂载状态（如 ClientOnly）。
- UI 组件的 className 一律通过 `clsxm(基础类, variantStyles[variant], props.className)` 组合，避免手写拼接。
- SVG 图标以单文件单组件形式存放于 `assets/icons/`，并在 `assets/index.ts` 中集中 re-export，调用方只从 `assets` 入口导入。
- 第三方或仅客户端运行的子功能（如 GoogleAds）使用 `next/dynamic` 配合 `{ ssr: false }` 动态引入，防止服务端渲染失败。
