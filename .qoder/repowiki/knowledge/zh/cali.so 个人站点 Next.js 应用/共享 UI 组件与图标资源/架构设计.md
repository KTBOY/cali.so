模块按职责分为三层：
- `components/ui/`：无业务语义的原子级 UI 控件（Button、Card、Container、Dialog、HoverCard、Tooltip），通过 `@zolplay/utils` 的 `clsxm` 合并 className，并统一支持 Tailwind + dark mode。
- `components/GameUi/`、`components/links/`、`components/portable-text/`：面向具体业务的组合组件，如游戏列表分页、Sanity Portable Text 渲染块、社交链接等，依赖上层页面路由与事件总线（如 `eventBus`）。
- 顶层散落的通用组件（Avatar、ClientOnly、Commentable、LiveAvatars、Multiplayer、PostPortableText、Prose、BleedThroughImage 等）作为跨页面复用的中间层。
- `assets/icons/` 下每个 SVG 导出一个独立 React 组件，统一由 `assets/index.ts` 重新聚合，对外暴露 `IconProps = React.SVGAttributes<SVGElement>` 类型；图片资源（Portrait.*）随包分发。
- 客户端组件通过 `'use client'` 指令显式声明，服务端不可直接访问；Google Ads 使用 `next/dynamic({ ssr: false })` 懒加载以避免 SSR 报错。
