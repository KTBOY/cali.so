模块以 `db/index.ts` 为唯一入口，使用 `@neondatabase/serverless` 创建连接池并通过 `drizzle(pool)` 暴露类型安全的 `db` 实例；`schema.ts` 用 `pg-core` 声明 `subscribers`、`newsletters`、`comments`、`guestbook` 四张表及其索引；`queries/` 下按实体拆分查询函数（如 `fetchGuestbookMessages`），统一通过 `~/db` 导入 `db` 实例并返回经 Hashids 编码后的 DTO；`dto/` 提供 Zod schema 与对应 TypeScript 类型，同时导出同名的 `Hashids` 实例用于将自增主键转为短 ID。依赖方向单向：`queries` → `schema` + `dto` → `index`，不反向引用上层业务逻辑。迁移文件位于 `migrations/`，由 Drizzle Kit 管理。
