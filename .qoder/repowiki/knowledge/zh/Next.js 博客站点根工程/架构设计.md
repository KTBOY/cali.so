根目录承担三件事：
- 运行时入口：`middleware.ts` 作为全站请求拦截器，先拉取 Vercel Edge Config 黑名单再写入 Upstash Redis，最后委托 `@clerk/nextjs` 的 `authMiddleware` 做鉴权；`next.config.mjs` 在构建/启动时 `import('./env.mjs')` 加载并校验环境变量。
- 外部服务连接点集中声明：`drizzle.config.ts` 指向 `db/schema.ts` + `DATABASE_URL`，`sanity.config.ts` 挂载 `/studio` 并引入 `~/sanity/plugins/settings`，`next.config.mjs` 允许 `cdn.sanity.io` 图片域名。
- 子模块消费契约由根级配置统一约束：所有子包通过 `~/` 路径别名被引用，`config_and_lib` 暴露 KV Key / Redis / Email 单例，`database` 暴露 Drizzle schema 与查询，`emails` 以 React 组件形式渲染，`sanity_cms` 提供 Groq 查询与 Studio 插件，`shared_components` 提供页面级 UI。当前为单包结构（`pnpm-workspace.yaml` 为空数组），由 `turbo.json` 对 `dev/build/lint` 定义缓存策略配合 `next dev --turbo` 使用。
