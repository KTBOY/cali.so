模块按职责分为三层：
- `components/ui/`：无业务语义的原子级控件（Button、Card、Container、Dialog、HoverCard、Tooltip），通过 `@zolplay/utils` 的 `clsxm` 合并 className，统一支持 Tailwind + dark mode。
- `components/GameUi/`、`components/links/`、`components/portable-text/`：面向具体业务的组合层，如 SWF 游戏列表与 Ruffle 播放器、社交链接、Sanity Portable Text 渲染块；其中 `GameUi/swfGames.ts` 以数据驱动方式声明游戏清单，`portable-text/*` 每个文件对应一个 block type。
- 顶层散落的通用组件（Avatar、ClientOnly、Commentable、LiveAvatars、Multiplayer、PostPortableText、Prose、BleedThroughImage、DomainAnnouncementDialog）作为跨页面复用的中间层。
- `assets/icons/` 下每个 SVG 导出一个独立 React 组件，统一由 `assets/index.ts` 重新聚合并暴露 `IconProps = React.SVGAttributes<SVGElement>` 类型；图片资源（Portrait.*）随包分发。
- 客户端组件通过 `'use client'` 指令显式声明，服务端不可直接访问；Google Ads 使用 `next/dynamic({ ssr: false })` 懒加载以避免 SSR 报错。
