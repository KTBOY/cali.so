- 每个文档类型文件同时导出 Sanity schema（`defineType`）和对应的 Zod schema，并通过 `z.infer` 生成 TypeScript 类型，保证后端数据契约与前端类型一致。
- Groq 查询采用 `groq` 标签模板字符串 + 同名 `client.fetch<T>(query, params)` 包装函数的成对模式，参数通过第二个位置传入而非拼接进模板。
- singleton 文档（如 settings）通过自定义 `definePlugin` 过滤 `newDocumentOptions` 与 `actions.duplicate`，并用 `StructureResolver` 将其固定为单条 ID 等于 type name 的文档。
- 环境变量统一经 `env.ts` 中的 `assertValue` 守卫后暴露，缺失时直接抛错，避免在运行时静默失败。
